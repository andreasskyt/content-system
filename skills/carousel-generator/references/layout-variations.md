# Layout variations

Different slide layouts you can pick between based on content. When the user provides a reference screenshot, identify which pattern matches, then rebuild with [BRAND] brand.

## Hero slide patterns

### A. Centered big statement (default)
One bold headline, logo lockup above or below. Minimal. Works for strong short hooks.

```
┌────────────────────────────────┐
│                                │
│   [[BRAND] lockup]        │
│                                │
│   Stop hiring editors.         │
│   Start shipping systems.      │
│                                │
│                                │
│   ━━━━━━━━━━━━━━━━━━━━  1/7    │
└────────────────────────────────┘
```

### B. Stat hero
One huge number + label. Works when a specific stat IS the hook.

```
┌────────────────────────────────┐
│                                │
│  [TAG: RESULTS]                │
│                                │
│   200                          │
│   videos / month               │
│   0 editors                    │
│                                │
│   ━━━━━━━━━━━━━━━━━━━━  1/7    │
└────────────────────────────────┘
```

### C. Quote hero
Big quotable line in quote marks. Name + title below. For testimonial-led or manifesto-style openers.

## Middle slide patterns

### D. Problem list (dark bg)
3-4 strikethrough pills or bullet points. Crossing out "what stops working".

```
┌────────────────────────────────┐ (dark)
│  [TAG: THE OLD WAY]            │
│                                │
│  ─Hiring editors─              │
│  ─Monthly retainers─           │
│  ─Slack threads─               │
│  ─Revision loops─              │
│                                │
│  ━━━━━━━━━━━━━━━━━━━━  2/7     │
└────────────────────────────────┘
```

### E. Shift / quote (gradient bg)
One line, big. Call-out style. The pivot point of the carousel.

### F. Feature list (light bg)
Icon + label + description per row. 3-4 rows.

```
┌────────────────────────────────┐ (light)
│  [TAG: WHAT'S UNDER THE HOOD]  │
│                                │
│  ● Auto-cut retakes            │
│    Claude picks the best take  │
│  ─────────────────────         │
│  ● Animated b-roll             │
│    40% coverage, no designer   │
│  ─────────────────────         │
│  ● Karaoke captions            │
│    Word-level highlighting     │
│                                │
│  ━━━━━━━━━━━━━━━━━━━━  4/7     │
└────────────────────────────────┘
```

### G. Numbered steps (dark bg)
Big numbers + short descriptions. How-to style.

### H. Big text with callout
One short statement taking 60% of canvas + small clarifying line below.

### I. Before / after split
Two columns or stacked blocks. Left/top = before, right/bottom = after.

```
┌────────────────────────────────┐
│  [TAG: BEFORE → AFTER]         │
│  ─────────────────┬───────────  │
│  BEFORE           │  AFTER     │
│  £1,500/mo editor │  $20/mo    │
│  5-day turnaround │  2 hours   │
│  Unpredictable    │  Consistent│
│  ─────────────────┴───────────  │
│  ━━━━━━━━━━━━━━━━━━━━  5/7     │
└────────────────────────────────┘
```

## CTA slide patterns

### J. Big statement + CTA button (default)
Brand gradient, one final punchy line, CTA button, @[IG_HANDLE] handle.

### K. Offer CTA
"Comment [word] and I'll DM you [specific deliverable]." Specific keyword + specific deliverable.

### L. Personal close
Short 2-sentence personal note + @[IG_HANDLE]. For longer emotional carousels.

## Matching reference screenshots

When the user provides an Instagram screenshot as inspiration:

1. **Identify each slide's pattern** from the list above (or describe it if it's a novel layout).
2. **Note the structural moves**: Did they open with a stat? Use a visual grid? End with a quote? Match the SEQUENCE of patterns.
3. **Do NOT copy their color palette or font.** Only the structural pattern.
4. **Adapt copy to [BRAND]'s voice.** Even if the reference uses longer sentences, compress to [BRAND]'s punchy rules — first-person singular (I/me/my), specific numbers, short lines. See `copy-patterns.md`.

Example:
> Reference is a @garyvee carousel with: hero stat → 3 reasons → quote slide → 3 more reasons → CTA.
> Your [BRAND] version: same structure (hero stat on slide 1 in [BRAND] colors → 3 reasons on dark bg → gradient quote slide → 3 more reasons on light → gradient CTA).

## Visual rhythm recap

Alternate light/dark across middle slides. Gradient slides (shift + CTA) are anchor points. Two of the same background in a row is a yellow flag — justify it or change one.
