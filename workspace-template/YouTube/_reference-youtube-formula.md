# YouTube Formula — Reference (distilled from Creator A, scanned 2026-08-29)

Full frameworks behind the rules in CLAUDE.md. Internal reference only — never credit Creator A in published content.

## 6-step video structure
0. **Packaging** — title/thumbnail first. Find an outlier video (VidIQ), diagnose why it worked, steal winning elements, write your OWN title.
1. **Intro** — open a curiosity loop, deliver on the title/thumbnail promise fast. Sub-framework: Belief Challenge → Credibility → Reflection → Big Promise → Instant Value (tease specifics).
2. **Credibility** — assume viewers don't know you. Personal numbers, client results, or reflection. Support with visuals (screenshots, dashboards, b-roll).
3. **Context** (~90–120s in) — backstory/relatability before the golden nuggets. Share the hard parts. Polarity bomb: "this isn't for [X], this is for [our tribe]".
4. **Core** — the actual framework. Number it ("the N-step system that…"), make it feel exclusive, polarize against industry norms.
5. **CTAs — three per video, never one:** first 90s = core lead magnet · middle = relevant next step · end = hook to next video.

## Scripting formula
Per video: **3 stories, 3 frustrations, 3 golden nuggets** — each as Setup (story) → Tension (viewer's frustration) → Payoff (nugget). Free-flow natural voice, ~1,500–2,000 words ≈ 12 min edited.

## 20-70-10 split
- 20% **Growth** — modeled on competitor outlier videos
- 70% **Authority** — the [YOUR_OFFER] method solving ICP pain points
- 10% **Conversion** — VSL / case-study breakdowns / client interviews

## Foundational Trio (evergreen assets every channel needs)
1. **Case Study** — "How [Client] went from X to Y in Z months." Dwell on the BEFORE (everyone relates to before, nobody to after). Steps → results with visual proof → give client the credit. Use before sales calls, in nurture, as ad creative.
2. **Unique Model / VSL** — the named method explained: authority hook → problem story → philosophy/analogy → 3 core components (what/why/how/example/common mistake each) → implementation blueprint → honest close.
3. **Industry Mistakes** — contrarian piece, ~7 mistakes × 2 min. Universal mistake pattern: direction, timing, focus, value, communication, comparison, legacy.

## Title formulas
- Case study: "How [Client] Went from $X to $Y in Z Months"
- Model: "My $X/Month [Industry] Method (Full [Name] Breakdown)"
- Mistakes: "[N] Mistakes [Industry] Make (And How to Avoid Them)"

## Cadence system
- First of month: fill content calendar, create ALL titles + thumbnails up front.
- Record 2 videos per session, ~2–3 hrs prep per video.
- Analyze after 2–4 weeks: read all comments for ideas, track section-level retention, spin follow-ups off high performers.
- No judging the channel before 50 videos. Volume + iteration beats theorizing.

## Content waterfall (per video)
One long-form video → reels per golden nugget/mistake → 1 carousel → email/DM assets. A "Mistakes" video alone = 7 reels + 7 emails + 1 pinned carousel.

## Anti-patterns
- Guest-expert interviews build THEIR authority, not yours.
- Bare outcome claims without context attract impatient low-quality leads.
- Don't give the full implementation away free — free holds no perceived value; teach the what/why, sell the done-for-you.
